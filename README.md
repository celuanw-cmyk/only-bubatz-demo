# Only Bubatz – Shop-Demo

Eine ansehbare Demo des Shopify-Themes **„Only Bubatz — Session 2026“**: Vintage-Headshop-Design mit Regal, Geheimschubladen, Kategorie-Filtern, Mengen-Staffeln, Versand-Countdown und Session-Seite.

## Demo ansehen

**https://celuanw-cmyk.github.io/only-bubatz-demo/**

Einfach den Link öffnen, am PC oder Handy. Alternativ: **Code → Download ZIP**, entpacken, `index.html` doppelklicken.

## Seiten

| Pfad | Inhalt |
|---|---|
| `index.html` | Startseite mit Regal und Geheimschubladen (echte Produkte) |
| `collections/<name>.html` | Alle 56 Kategorien/Marken-Sammlungen, dazu `collections/all.html` mit allem |
| `products/<name>.html` | Alle 449 aktiven Produkte mit echten Varianten und Mengen-Staffeln |
| `pages/sessions.html`, `pages/ueber-uns.html`, `pages/mix.html` | Bubatz Session, Über uns, Mix & Match |
| `pages/impressum.html`, `agb`, `gdpr`, `widerrufsrecht`, `versand`, `zahlungsarten`, `faq`, `contact` | Info- und Rechtsseiten |
| `cart.html`, `search.html` | Warenkorb (Beispiel), Suche |

## Hinweise

- Produkte, Preise und Bestände stammen aus einem Datenstand vom 4. November 2026 und sind nicht live.
- Warenkorb und Kasse sind in der Demo **abgeschaltet**.
- Einige Bilder werden aus dem Shopify-CDN geladen und brauchen Internet.
- Die Demo ist eine Vorschau des Theme-Codes, nicht der Live-Shop.
